# 🚀 ZooniAI – AI Search & Knowledge Assistant

An AI-powered search platform that enables users to access answers, insights, and knowledge from multiple AI systems and information sources through a single unified interface.

## 🌐 Live Demo

https://amanlakeviya.github.io/ZooniAI/

## 🌟 Overview

ZooniAI simplifies information discovery by bringing together multiple AI systems and external knowledge sources into one seamless search experience.

Instead of switching between different AI assistants, search engines, and information platforms, users can access everything from a centralized interface designed for faster research and productivity.
